# GCU Lahore Website Clone – HTML Practice

## About the Project

This project is a basic HTML practice assignment in which I created a simple webpage inspired by the Government College University (GCU) Lahore website.

The main purpose of this project was to practice HTML fundamentals and understand how different HTML elements work together to structure a webpage.

## Features

- Header section with university name and logo
- Main banner image
- Navigation menu with links
- Contact information section
- Location details
- Contact form with input fields
- Text area for messages

## Technologies Used

- HTML5
- Visual Studio Code

## What I Practiced

While working on this project, I practiced:

- Basic HTML document structure
- HTML tables and table rows
- Headings, paragraphs, and text formatting
- Images and hyperlinks
- Forms and input fields
- Textarea elements
- Inline CSS styling
